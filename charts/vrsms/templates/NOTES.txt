Reach the application:

  minikube service {{ include "vrsms.fullname" . }} --namespace {{ .Release.Namespace }} --url

Or port-forward, which also works inside a Codespace:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "vrsms.fullname" . }} 8081:{{ .Values.service.port }}
  curl http://localhost:8081/actuator/health

Inspect what is running:

  kubectl --namespace {{ .Release.Namespace }} get all
  kubectl --namespace {{ .Release.Namespace }} logs deploy/{{ include "vrsms.fullname" . }} -f
  helm history {{ .Release.Name }} --namespace {{ .Release.Namespace }}

Roll back the previous deploy:

  helm rollback {{ .Release.Name }} --namespace {{ .Release.Namespace }}
